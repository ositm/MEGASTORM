# LabLink Handoff Folder

Everything you need to pitch, test, or resume work on LabLink — readable from any device via GitHub.

| File | What it is |
|---|---|
| [LABLINK_OVERVIEW.md](LABLINK_OVERVIEW.md) / [LabLink_Overview.pdf](LabLink_Overview.pdf) | The pitch-ready deep dive: what's built, how the workflow operates, and step-by-step test-drive instructions for every platform (patient, collector, courier, lab, admin) |
| [ELEVATOR_PITCH.md](ELEVATOR_PITCH.md) / [Elevator_Pitch.pdf](Elevator_Pitch.pdf) | The one-liner, 30-second, and 10-second pitches |
| [PROJECT_STATE.md](PROJECT_STATE.md) | Technical snapshot to resume the next working session from |

## Reading this from your phone

Open the **GitHub app** (or github.com in your phone's browser) → repository `ositm/MEGASTORM` → `docs/handoff/`. Markdown renders inline; tap the PDFs to view or share them — the PDF is what you forward to an investor or pilot lab.

## Resuming work later

1. Connect the external drive (project lives at `D:\LabLink\MEGASTORM`).
2. Open the editor / Claude Code in that folder.
3. Say: *"Resume from docs/handoff/PROJECT_STATE.md"* — that file plus the session memory carries the full context.
